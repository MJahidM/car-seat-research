# Convertible car seat research — Mazda CX-70

Choosing a convertible car seat for a 2026 Mazda CX-70 plug-in hybrid, with particular
attention to whether the centre position of the second row can be used.

**Read it here: https://mjahidm.github.io/car-seat-research/**

The page is password protected. The contents are encrypted with AES-GCM and are not
readable without the password.

## What is in it

- Second-row findings with the vehicle manual quoted: lower anchor layout, the
  restrictions that apply to the centre position, tether anchors, and measured clearances
- Notes from a consultation with a certified child passenger safety technician
- A comparison of convertible seats using independent instrumented crash testing
- The new federal side-impact standard taking effect 5 December 2026
